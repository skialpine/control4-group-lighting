# 2026111504 — Reliability test build

Builds on the shared light engine port in 2026111502. This package is for
testing; preparing it does not update Director or change the installed driver.

- Missing startup levels remain unknown until a light reports a level.
- A member send exception is logged and the remaining members still receive
  commands.
- Unloading cancels transport queues and light engine timers.
- Control logs include millisecond timing, command identities, transport and
  feedback, plus an engine snapshot. Feedback identities refer to the latest
  command for that member/aspect; they are not device acknowledgements.
- The shared display callback includes brightness and full color. Scene reads
  use a supported authenticated UI helper, including development login.
- Fresh Lua reload tests retain saved rates, presets and member selection. A
  simulated project exercises three independent standard, native and mixed
  transport groups.

The shared additions are local changes against template v0.9.109, preserved in
`resources/template/light-reliability.patch`; they are not a published template
release.

For testing, update one group first. Confirm its selected lights and saved
rates, then try on/off, a slow brightness fade, color while off, scene
activation, and an individual member changed manually. Repeat with the other
groups and capture Display Control Log if a light pauses or drifts. Controller
testing remains necessary; the automated reload tests do not simulate a Director
process restart.
