# 2026111502 — Shared light engine test build

Updates the template to v0.9.109 and ports Light Group to its shared Light V2
engine. Existing group selections, saved settings, tracking modes, color
temperature mapping and emulation, and scene cycling are retained.

Lights that answer the template's group handshake receive brightness and color
in one command. Standard Light V2 lights retain the universal command path,
including suppression of an unchanged color before a brightness ramp.

An off member is sent the group's color when it rejoins an already-on group. The
Settings tab now includes color when marking a member as in step.

This is a local test build for installation in Composer. Check app and keypad
on/off, ramps and release, color changes, scene cycling, and the member that
previously drifted. Hardware behavior has not yet been verified.
