# 2026111003 — Revert startup brightness changes

Restores the lighting behavior from 2026111001. The startup brightness,
missing-data handling, and proxy retry changes introduced in 2026111002 have
been reverted. Version 2026111002 has been withdrawn.

The Home Assistant brightness error is still under investigation. Those changes
were not established as its cause or solution.

Select **Update Channel → Prerelease**, then run **Actions → Update Drivers**.
The driver should show **2026111003** afterward. This higher version lets a
controller already running 2026111002 receive the restored code through the
normal updater. Existing groups and selected lights are retained.
